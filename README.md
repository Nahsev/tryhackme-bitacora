# Bitácora de Ciberseguridad

Registro público de mi aprendizaje en ciberseguridad, desde cero, con [TryHackMe](https://tryhackme.com/p/Nahsev).

Cada sala que completo queda acá con su camino, dificultad y los comandos que fui usando. Sin flags ni respuestas de salas: solo el proceso.

## Ver el sitio

- **GitHub Pages:** https://nahsev.github.io/tryhackme-bitacora/
- **Vercel:** (se agrega al importar el repo)

## Cómo está armado

- `index.html` — la página, sin dependencias ni build.
- `rooms.json` — los datos de las salas. Se actualiza a medida que avanzo.

Para correrlo localmente, cualquier servidor estático sirve, por ejemplo:

```
python3 -m http.server
```

y abrir http://localhost:8000

## Progreso

Arrancando por el camino **Pre Security**. La idea es sumar, más adelante, un resumen con mis palabras de lo más importante de cada tema.
